# Image-Based Steganography Tool

- Built a Python GUI (Tkinter + PIL) encoding and decoding hidden messages within image files demonstrating applied image data manipulation and programming skills. This program hides encrypted text inside digital images using least significant bit (LSB) encoding techniques.

## Features

- Hide secret text messages inside images
- Decode hidden messages from encoded images
- PNG image support
- Simple Python implementation
- Research paper included

## Technologies

- Python
- Pillow (PIL)
- NumPy
